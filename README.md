# FTB Project EX (Minecraft 1.7.10 Backport)

A complete 1.7.10 backport of **Project EX**, an expansion mod for **ProjectE** originally created by *LatvianModder* / *FTB Team* for Minecraft 1.12.2.

---

## 🌟 Key Features

* **EMC Links:**
  * **Basic Energy EMC Link:** Collects EMC from connected Collectors and deposits it into your Personal EMC network.
  * **Personal EMC Link:** Allows item import/export connected directly to your Personal EMC network.
  * **Refined EMC Link:** Features 1 input and 9 output slots for automated item extraction systems.
  * **Compressed Refined EMC Link:** Features 54 output slots for massive automation pipelines.

* **Collectors & Relays (Tiers MK1 – MK15 & The Final Collector/Relay):**
  * **Collectors (16 Tiers):** Generates EMC once per second (TPS-friendly).
  * **Relays (16 Tiers):** Transfers EMC once per second with tier-scaled bonuses.

* **Power Flower Bonsai Pots (16 Tiers):**
  * Compact single-block Power Flowers generating passive EMC directly to your network.

* **Stone Transmutation Table:**
  * Sleek 4-pixel high stone slab providing full access to ProjectE's Transmutation Table GUI.

* **Expanded Stars & Items:**
  * **Klein Stars:** Tiers Ein to Omega.
  * **Magnum Stars:** Tiers Ein to Omega (massive EMC storage).
  * **Colossal Stars:** Tiers Ein to Omega (end-game EMC storage).
  * **The Final Star & Shard:** Infinite item duplication capability.
  * **Knowledge Sharing Book:** Bind and share player learned transmutation knowledge.
  * **New Matter Types (12 Tiers):** Magenta, Pink, Purple, Violet, Blue, Cyan, Green, Lime, Yellow, Orange, White, and Fading Matter.

## 📋 Requirements

* **Minecraft:** `1.7.10`
* **Minecraft Forge:** `10.13.4.1614` or newer
* **ProjectE:** `1.7.10-PE1.10.1` or newer

---

## ⚙️ Building from Source

This project uses **RetroFuturaGradle** for building:

```bash
# Clone the repository
git clone https://github.com/YatzCore/FTB-ProjectEX-1.7.10.git
cd FTB-ProjectEX-1.7.10

# Build the mod
./gradlew build
```

The production compiled `.jar` file will be generated in `build/libs/FTB-ProjectEX-1.7.10-1.0.0-1.7.10.jar`.
